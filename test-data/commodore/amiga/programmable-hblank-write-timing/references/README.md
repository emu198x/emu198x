# Write-Timing References

This directory records which evidence can answer the corpus's mid-line
register-write questions.

Reference captures must preserve the visible marker and adjacent control
rows, identify the exact suite artifact and machine configuration, and record
all normalisation. A stable software-emulator result remains
software-derived evidence. It is not physical-hardware evidence.

The registered FS-UAE package records the current UAE-family result.
Copperline 0.13.0 and vAmiga 4.4b12 cannot execute this question through an
admissible video path; their limitations are recorded in
[`comparator-capabilities.md`](comparator-capabilities.md).

No physical-hardware capture is registered.
