# Capture records

This directory contains one capture record per profile and case.

Records conform to
[`../../../schema/capture-v1.schema.json`](../../../schema/capture-v1.schema.json).
Each identifies the suite artifact, UAE-family producer, machine and firmware
hash, field procedure, raw geometry, source-derived beam mapping, observed
blank edges, and provenance.

The records describe producer observations. They do not promote unresolved
corpus expectations.
