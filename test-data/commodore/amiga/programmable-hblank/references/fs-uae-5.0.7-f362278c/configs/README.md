# Captured configurations

This directory retains the exact generated UAE configuration used by every
run.

Absolute paths identify the isolated capture directories and external
firmware location on the capture host. They are retained for provenance and
are not portable templates. The reusable template is in
[`tools/fs-uae-hblank-capture/config.uae.in`](../../../../../../../tools/fs-uae-hblank-capture/config.uae.in).
