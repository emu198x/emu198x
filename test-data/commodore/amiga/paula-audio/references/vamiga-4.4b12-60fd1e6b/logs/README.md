# Producer logs

This directory contains the complete adapter output for each case and the
CMake configure-and-build log for the shared producer binary.

The case logs record only the adapter's completion summary. Detailed ready
record, field, sample-count, and audio-buffer state is retained under
[`../manifests/`](../manifests/README.md).

No firmware bytes, compiled producer, or absolute invocation command is
included.
