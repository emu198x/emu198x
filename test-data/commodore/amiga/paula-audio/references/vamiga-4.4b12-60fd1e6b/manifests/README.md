# Capture-time manifests

This directory contains the adapter's unmodified JSON result for each case.

Each manifest records the validated `PAUD` fields, vAmiga and guest field
labels, samples produced per captured field, total sample frames, and
audio-buffer fault counters. These are capture-stage facts, not
cross-producer conclusions.

The reviewed evidence records under [`../records/`](../records/README.md)
bind these facts to producer, machine, firmware, configuration, waveform, and
semantic observations.
