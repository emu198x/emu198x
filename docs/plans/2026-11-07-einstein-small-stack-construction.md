# Keep Einstein runtime construction within a small native stack

The read-only 35 CLI audit following the Game Boy Windows failure reproduced a second failure: the unchanged Einstein debug script and MCP processes abort with a 1 MiB stack. Normal and 2 MiB runs pass and observe the pinned synthetic MOS byte; help passes all limits. Other audited candidates pass their loaded-media controls. Native ARM diagnostic sizes are 82,944 bytes for Einstein and 83,264 for EinsteinRuntime, including private 64 KiB RAM and inline VDP state. Nested launcher/runtime constructor frames exceed 1 MiB. This is not a Windows disassembly measurement or a claim about every shipping release.
