# Defer Amiga debugger framebuffer conversion

Lane: engineering-frontier validation. The Code198x timed-turn caller exposes a host debugger performance defect on released v0.44.2, not a failure of its normal IRQ clock. A 500-instruction bounded run takes 3.1907 seconds; waiting for the next VBlank through run_until_pc exceeds the 60-second transport timeout. Normal run_frames advances 100 IRQ ticks in 100 frames.

Root cause: runtime `account_debug_progress` calls the full ARGB-to-RGBA conversion and three pixel diagnostics after every system tick crossed by exact CPU stepping. The Amiga DebugPrimitives implementation also inherits the fallback no-resync method, so the shared debugger cannot defer that work as it does on other machines. Read maintained shell debug macros before adding another mechanism; no archive port is needed. The three configured legacy archive paths are absent in this host. No chip, CPU, bus, IRQ or oscillator behaviour changes.

1. Add a failing regression in `crates/runtime-commodore-amiga/src/runtime.rs`: the existing shared no-resync step leaves a deliberately stale frame mirror/diagnostics untouched until explicit resync. Compare CPU boundaries/state, machine/runtime time, audio samples/phase and final frame against ordinary stepping on OCS, ECS, AGA and accelerated OCS.
2. In the same runtime file, keep audio and tick accounting in every exact advance but defer pixel conversion. In `cpu_trace.rs`, document the private boundary advance's deferred-output contract. In `variants.rs`, provide a private no-resync instruction span and keep the existing exact-step method coherent via one final refresh. In `debug.rs`, implement the existing shared no-resync/resync hooks with those methods. No new architecture or dependencies.
3. Run the new test red before the fix and green afterwards, the complete runtime tests including stopped-CPU and multi-edge exact-boundary regressions, formatting and Clippy for the changed crate.
4. Build the native Amiga executable and repeat the bounded real-caller benchmark; compare ticks/steps and run the actual next-frame target to completion. Use an isolated target directory and do not commit firmware/private snapshots.
5. Commit/push a separate fix PR with source/evidence links and no merge. Keep the twelve Code198x paired stacks separate. Preserve logs, commits and remote refs, inventory untracked/ignored files, then remove this task worktree and build cache before final completion.
