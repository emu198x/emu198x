# Atari 2600 (VCS)

## Status: Boots carts; Combat renders and is playable

Headless extended system (Capture + Script + MCP, no native window yet). Combat
boots to its two-tank playfield; the joystick is validated against MAME. 6507
(pin-limited 6502) + TIA + RIOT (6532).

## What works

- **6507 CPU** — `mos-6502` running as the 6507 (13 address lines).
- **TIA** — pixel-level rendering for normal cart paths; A12/A7/A9 address
  decode; WSYNC halts the CPU until hblank.
- **RIOT (6532)** — timer + I/O; free-running prescaler (see disproven below).
- **Cart banking** — 2K/4K (none), F8 (8K), F6 (16K), F4 (32K) hotspot banking.
- **Joystick** — validated at the register level: P0 in SWCHA high nibble, P1 in
  low nibble, active-low, per MAME `switch_A_r` (fixed this session, `fb44ad3a`).
  `vcs.input.swcha/swchb/inpt4/inpt5` queries added.

## Not implemented / accuracy gaps

- **TIA cycle-perfect timing** — HMOVE quirks, RESP starfield edge cases, audio
  mixing refinements outstanding. Bigger games (Pitfall, Adventure, Star Raiders)
  may surface issues.
- **Audio** — TIA AUDx registers latch but no WAV drain.
- **Snapshot** — deferred (shared family pattern).
- **No native window.**

## Known unknowns / disproven hypotheses

- **DISPROVEN: "the joystick wiring is fine."** Players 0/1 were swapped between
  SWCHA nibbles; fixed against MAME `switch_A_r` (`fb44ad3a`).
- **DISPROVEN (donor): "reading INTIM resets the timer prescaler."** Real 6532
  silicon doesn't touch the prescaler on a read — the timer free-runs. Combat
  polls INTIM in a tight loop expecting the prescaler to keep decrementing; the
  donor's reset-on-read meant the wait loop never exited. Fixed: reading INTIM
  clears only the underflow flag.
- **Verification targets** — TIA HMOVE / RESP / audio-mixing behaviour against
  the Stella Programmer's Guide + reference emulators before treating the TIA as
  accurate.

## Validated against

- MAME `a2600.cpp` (`switch_A_r` joystick layout); Stella (reference).
- Combat (1977, 2K NTSC) boot smoke `tests/cart_boot.rs` (1/1).

## Timing & cycle-accuracy

- **Master clock & dividers** — the TIA colour clock is the master: 3.579545 MHz
  NTSC / 3.546894 MHz PAL. The 6507 and RIOT tick every **3rd** colour clock;
  TIA WSYNC halts the CPU until the next hblank.
- **Timing model realised** — among the more accurate donors: pixel-level TIA
  rendering, colour-clock-driven, with the genuine race-the-beam halting. The
  6507/RIOT 3:1 relationship is the real hardware ratio.
- **CPU timing** — 6507 cycle-accurate (§62; Tom Harte validates the 6502 ISA).
- **Distance to full cycle-accuracy** — TIA HMOVE quirks, RESP starfield edge
  cases, audio mixing; bigger games (Pitfall, Adventure) may surface gaps.

## Tooling & drivability

- **Script / MCP** — `--script` + `--mcp`; `vcs.input.*` query paths added this
  session.
- **Native window** — headless only (extended tier).
- **Disassembler** — pending the Asm198x shared 6502 disassembler.

## Peripherals & connectivity

- **Emulated now** — joystick (+ console switches, SWCHA/B queries), paddles
  (TIA INPT0-3 pot charge timing, `c2861c08`).
- **Period peripherals (emulatable)** — driving controller, keyboard
  controllers, light gun (Video Touch Pad / Kid Vid).
- **Internet-capable** — **Yes** (and delightfully so): the **CVC GameLine**
  (1983) was a cartridge *modem* that downloaded games over the phone line — a
  fully period, documented, emulatable net device. The 2600 was online in 1983.
