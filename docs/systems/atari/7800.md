# Atari 7800 ProSystem

## Status: Renders carts (Asteroids draws); fire button wired

Headless extended system. After the MARIA fixes the display-list processor walks
real content and Asteroids renders. 6502C "Sally" + MARIA (zone display
processor) + RIOT + a thin TIA-audio stub.

## What works

- **MARIA** — DLL/zone walk, per-line DMA, correct DL-entry parse (4- vs 5-byte
  per entry), direct + indirect/char modes, holey DMA, two's-complement width.
- **Cart mapping** — flat 16K/32K/48K or 8×16K SuperGame banking; A78 header
  stripped.
- **Input** — joystick via RIOT port A (active-low); console switches; **fire +
  second-button via TIA INPT0-5** (`set_fire`/`set_fire2`, this session).

## Not implemented / accuracy gaps

- **MARIA mode coverage** — 160B / 320B/C/D and Kangaroo transparency need a
  visual diff against a reference (sibling of the 5200 ANTIC/GTIA work).
- **BIOS overlay** — not modelled (games boot from their own reset vector;
  authenticity, not a blocker).
- **TIA audio** — six registers stored, no synthesis.
- **Snapshot** — deferred. **No native window.**

## Known unknowns / disproven hypotheses

- **DISPROVEN: "the black screen is a missing BIOS."** Tracing Asteroids showed
  it runs its own reset at `$D000` and spins waiting on zero-page `$76`, advanced
  only by its DLI NMI. Real cause: the MARIA CTRL (`$3C`) bit map was wrong on
  three bits — DMA-enable, colour-kill, Kangaroo — so a game enabling DMA read as
  "DMA off", MARIA never walked the list, no DLI → no NMI → `$76` frozen → black.
  Corrected against the MiSTer RTL (2026-06-04).
- **DISPROVEN: "the DL-entry parser was right."** It had never run on real
  content; rewritten to the hardware format, cross-checked vs MiSTer `DMA.sv`.
- **Verification target** — graphics-mode fidelity + transparency vs a reference
  frame.

## Validated against

- MiSTer 7800 RTL (`DMA.sv`) — MARIA CTRL bits + DL-entry format.
- Asteroids (1987 NTSC) renders (~18 colours, ~5k non-bg px); `tests/cart_boot.rs`
  asserts a rendered frame. `atari-maria` 15/15 tests.
