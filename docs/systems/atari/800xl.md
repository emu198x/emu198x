# Atari 800XL

## Status: Native window; boots to BASIC READY with text rendering; keyboard types

Has its first native window on the shared `emu198x-ui` harness (#460). The full
OS → SIO-timeout → BASIC chain runs, GR.0 text now genuinely **renders to the
framebuffer** (see the char-set fix below — it previously reached the READY
*state* but only the cursor painted), and typed keys reach the BASIC editor.
6502C "Sally" + ANTIC + GTIA + POKEY + PIA (6520).

## What works

- **Boot to BASIC `READY`** (2026-06-03), GR.0 text path correct (DL LMS/DLI,
  hi-res text colour, CHACTL cursor). Types `PRINT 6*7` → `42`.
- **GR.0 character glyphs render** (2026-06-23) — ANTIC fetches the font from
  `$E000` in the OS ROM via a ROM-overlaid `antic_mem` view; before this it read
  bare RAM (font = 0) so only the inverse-video cursor painted. See the char-set
  fix below.
- **Native window** — `emu198x-ui` harness: wgpu video, keyboard typing,
  arrows/gamepad → joystick, F2/F3/F4 → Start/Select/Option.
- **ROM banking** via PIA PORTB (OS / BASIC / self-test overlays).
- **Input** — joystick via PIA PORTA, fire via GTIA TRIG0, console keys via GTIA
  CONSOL.
- **MCP debug surface** — `query_cpu/antic/gtia/pokey/pia`, `memory_read`
  (banked), `poke_*`, `run_until_pc`, `press_key`/`type_string` (matches the
  Spectrum/Amiga "agent can drive it" bar).

## Not implemented / accuracy gaps

- **POKEY audio** — unwired in the binary.
- **XEX / disk (SIO + ATR)** — not implemented; cart-only / cart-with-OS for now.
  The next Tier-1 feature.
- **`disasm` MCP tool** — parked on Asm198x promoting its 6502 disassembler to a
  shared crate.
- **130XE extended-RAM banking; 400/800 variants** — deferred (model flag).
- **Snapshot** — deferred.

## Known unknowns / disproven hypotheses

- **Seven boot bugs resolved end-to-end** (the dead ends, recorded so they aren't
  re-walked): PIA A0/A1 address cross-wire, ANTIC NMIEN VBI/DLI bit swap, DL
  LMS/DLI decode, CHACTL cursor inversion, GTIA hi-res text colour, GTIA CONSOL
  read/write split, POKEY edge-latched serial transmit. Full record:
  `docs/solutions/atari-800xl-sio-disk-boot-to-basic.md`.
- **GR.0 glyphs didn't actually render** (fixed 2026-06-23) — the seven fixes
  above made the *cursor* paint, and the boot-probe's "3 distinct colours" check
  plus the screen-RAM "READY" check both passed, so the system was logged as
  "GR.0 text renders". It did not: ANTIC was handed bare `ram`, so the `$E000`
  character set (in the OS ROM) fetched as zeros — every normal glyph was blank
  and only the inverse-video cursor (`!0 = $FF`) showed. Found by a framebuffer
  probe (64 non-bg px = one cell) once the native UI made the blank screen
  visible. Fixed by giving ANTIC a ROM-overlaid `antic_mem` view (matches the
  5200's `dma_mem`), validated against `atari800` `antic.c` (`INIT_ANTIC_2` reads
  the font from `MEMORY_mem`, ROM included). A pixel-level guard now lives in
  `boots_to_basic_ready`. Classic *assert-output-not-state* miss.
- **Note:** the 5200's partial-render gap is a *different* ANTIC mode path; this
  GR.0 fix does not close it.
- **Verification target** — SIO/ATR disk protocol (now tractable via the MCP
  memory/run-until-pc tools).

## Timing & cycle-accuracy

- **Master clock & dividers** — colour clock master; CPU ≈ 1.79 MHz NTSC. ANTIC
  DMA per scanline.
- **Timing model realised** — **per-colour-clock GTIA** (2026-06-08): the machine
  hands ANTIC each scan line at its left edge and composites the playfield
  left-to-right from the *live* colour registers as the beam advances, so a
  mid-line `COLBK`/`COLPF` write (rainbow / gradient / split-screen colour
  kernels) recolours only the pixels drawn after it. **Players, missiles and
  collisions are also evaluated per pixel from the live registers** (phase 3),
  so mid-line `HPOS`/`GRAFP` rewrites multiplex a sprite across the line and
  collisions accumulate (and `HITCLR`s) at the beam. GR.0 text renders correctly.
  **ANTIC DMA is spread across the display-fetch window** `[cycle 32, 104)`
  (phase 4) rather than front-loaded at the line start, so a mid-line write
  lands near the right beam position; and a **`STA WSYNC` releases the CPU at
  HSYNC (cycle 104)**, not the next line. Both cite MAME `antic.cpp`
  (`CYCLES_HSTART` / `CYCLES_HSYNC`).
- **CPU timing** — 6502 "Sally" cycle-accurate (§62).
- **Distance to full cycle-accuracy** — the DMA spread is an even split across
  the fetch window, not the exact per-character steal positions (a relaxation
  MAME shares — it block-steals); broader ANTIC mode coverage; POKEY audio.

## Tooling & drivability

- **Script / MCP** — strong: `--script` + `--mcp` with
  `query_cpu/antic/gtia/pokey/pia`, banked `memory_read`, `poke_*`,
  `run_until_pc`, `press_key`/`type_string`. Matches the Spectrum/Amiga
  agent-drivable bar. The one gap is `disasm`.
- **Native window** — **yes** (#460), on the shared `emu198x-ui` harness: wgpu
  video with raw/lcd/crt filters, keyboard typing, arrows/gamepad → joystick,
  F2/F3/F4 → console keys. Boot + keyboard + render all confirmed visually.
- **Disassembler** — `disasm` parked on the Asm198x shared 6502 disassembler.

## Peripherals & connectivity

- **Emulated now** — joystick + fire, console keys, keyboard into BASIC.
- **Period peripherals (emulatable)** — the **SIO** chain: 810/1050 disk, 410
  cassette, 850 interface, 1020 printer/plotter; paddles, touch tablet, light pen.
- **Internet-capable** — **Yes** (a highlight): period SIO modem via the 850
  interface, and the modern **FujiNet** — a WiFi SIO device with a documented
  protocol, purpose-built to put Atari 8-bits online. A prime emulation target.
