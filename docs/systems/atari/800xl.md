# Atari 800XL

## Status: Boots to BASIC READY; keyboard types — furthest-advanced donor system

Headless extended system, and the strongest candidate for the first native
window outside the primary six. The full OS → SIO-timeout → BASIC chain runs,
GR.0 text renders, and typed keys reach the BASIC editor. 6502C "Sally" + ANTIC +
GTIA + POKEY + PIA (6520).

## What works

- **Boot to BASIC `READY`** (2026-06-03), GR.0 text path correct (DL LMS/DLI,
  hi-res text colour, CHACTL cursor). Types `PRINT 6*7` → `42`.
- **ROM banking** via PIA PORTB (OS / BASIC / self-test overlays).
- **Input** — joystick via PIA PORTA, fire via GTIA TRIG0, console keys via GTIA
  CONSOL.
- **MCP debug surface** — `query_cpu/antic/gtia/pokey/pia`, `memory_read`
  (banked), `poke_*`, `run_until_pc`, `press_key`/`type_string` (matches the
  Spectrum/Amiga "agent can drive it" bar).

## Not implemented / accuracy gaps

- **POKEY audio** — unwired in the binary.
- **XEX / disk (SIO + ATR)** — not implemented; cart-only / cart-with-OS for now.
  The next Tier-1 feature.
- **`disasm` MCP tool** — parked on Asm198x promoting its 6502 disassembler to a
  shared crate.
- **130XE extended-RAM banking; 400/800 variants** — deferred (model flag).
- **Snapshot** — deferred. **No native window** (best candidate to get one).

## Known unknowns / disproven hypotheses

- **Seven boot bugs resolved end-to-end** (the dead ends, recorded so they aren't
  re-walked): PIA A0/A1 address cross-wire, ANTIC NMIEN VBI/DLI bit swap, DL
  LMS/DLI decode, CHACTL cursor inversion, GTIA hi-res text colour, GTIA CONSOL
  read/write split, POKEY edge-latched serial transmit. Full record:
  `docs/solutions/atari-800xl-sio-disk-boot-to-basic.md`.
- **Note:** the 5200's partial-render gap is a *different* ANTIC mode path; this
  GR.0 fix does not close it.
- **Verification target** — SIO/ATR disk protocol (now tractable via the MCP
  memory/run-until-pc tools).
