# Sinclair ZX80

## Status: Boot screen (FAST mode); SLOW-mode render pending

Sinclair's £100 launch machine (1980, ~100,000 units). Renders the canonical
FAST-mode display with the "K" cursor. Headless extended system. Z80 +
`sinclair-zx81-ula` (same ULA silicon as the ZX81 — only the NMI wire and ROM
size differ).

## What works

- **FAST-mode display** — the "K" cursor is visible; character output renders
  through the ULA pipeline (ZESARUX `zx80.rom`, 4K, 2026-06-01).
- **Memory** — 4K ROM `$0000-$0FFF` mirrored to `$1000-$3FFF` and `$8000-$BFFF`;
  1K/16K RAM `$4000-$7FFF` mirrored to `$C000-$FFFF`.
- **Keyboard** — 8×5 Spectrum-style matrix via port `$FE`.

## Not implemented / accuracy gaps

- **SLOW mode** — the v1 ULA model blanks the screen during CPU execution and
  renders only during HALT, which doesn't yet match real hardware; only FAST mode
  is correct.
- **Cassette I/O** unwired. **Snapshot** deferred. **No native window.**

## Known unknowns / disproven hypotheses

- **Open: SLOW-mode rendering** — the display-during-HALT model is the known gap;
  needs validation against ZX80 hardware behaviour.
- **Verification target** — the FAST/SLOW (no-NMI vs HALT-render) distinction
  against a ZX80 reference.

## Validated against

- `sinclair-zx81-ula` (shared, 6/6 tests); ZESARUX `zx80.rom` FAST render.

## Timing & cycle-accuracy

- **Master clock & dividers** — Z80 at 3.25 MHz; same ULA silicon as the ZX81 but
  no NMI wire (FAST-only display).
- **Timing model realised** — relaxed and partial: FAST mode renders; **SLOW-mode
  (display-during-HALT) is not yet correct**.
- **CPU timing** — Z80 cycle-accurate (§62).
- **Distance to full cycle-accuracy** — the SLOW/FAST display model; beam-accurate
  ULA timing.

## Tooling & drivability

- **Script / MCP** — `--script` + `--mcp`.
- **Native window** — headless only (extended tier).
- **Disassembler** — pending the Asm198x shared Z80 disassembler.

## Peripherals & connectivity

- **Emulated now** — keyboard, ULA display (FAST).
- **Period peripherals (emulatable)** — RAM pack, cassette.
- **Internet-capable** — **No**: a minimal 1980 machine with no realistic period
  or modern net path.
