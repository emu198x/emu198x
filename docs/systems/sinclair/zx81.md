# Sinclair ZX81

## Status: Boot screen renders

The £49.95 follow-up to the ZX80 (1981, ~1.5M units). Renders real character
output from D_FILE through the ULA. Headless extended system. Z80 +
`sinclair-zx81-ula`.

## What works

- **NMI-driven bus-stealing display** — the NMI handler at `$0066` executes HALT;
  the ULA puts character-ROM data on the bus during the Z80 refresh cycles. NMI
  generator gated by an enable bit (OUT `$FE` on / OUT `$FD` off).
- **Memory** — 8K ROM `$0000-$1FFF` mirrored to `$2000-$3FFF` and `$8000-$BFFF`.
- **Keyboard** — 8×5 Spectrum-style matrix via port `$FE` (row selector in the
  high address byte).
- **Boot screen** renders (ZESARUX-bundled `zx81.rom`, 8K).

## Not implemented / accuracy gaps

- **`.p` / `.p81` snapshot load** — not implemented (donor didn't have it).
- **Cassette I/O** unwired. **Snapshot** deferred. **No native window.**

## Known unknowns / disproven hypotheses

- **Open: interactive typing / running.** Boot renders; full type-and-execute
  isn't confirmed on this page (the ZX81's display is the interactive surface).
- **Verification target** — NMI/HALT display timing + keyboard against a ZX81
  reference (the ULA crate has 6/6 unit tests but the system-level interactive
  path isn't ledgered as verified).
