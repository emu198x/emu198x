# Commodore 64

## Status: Fully functional — per-cycle VIC-II, accurate SID, IEC bus, datasette

The C64 boots the KERNAL ROM, loads software from D64 disk images (via IEC serial bus), TAP tape images (via datasette), and PRG files. All standard display modes, 8 hardware sprites with collision detection, and accurate SID audio with filter emulation.

## What works

- **CPU:** MOS 6502 — all 151 official opcodes, undocumented opcodes (LAX, SAX, DCP, ISC, SLO, RLA, SRE, RRA, ANC, ALR, ARR, AXS), BCD mode with correct N/V/Z timing, JMP indirect page bug. 2,560,000 Tom Harte tests passing.
- **Video (VIC-II):** Per-cycle rendering (8 pixels per tick). All display modes: standard/multicolour character, standard/multicolour bitmap, ECM. 8 hardware sprites with multicolour, X/Y expansion, priority ($D01B — sprites behind foreground), and collision detection (sprite-sprite $D01E, sprite-data $D01F with IRQ). Bad line detection with VC/VCBASE/RC sequencer. BA line halts CPU after 3 cycles (cpu_debt model). Sprite DMA cycle stealing. XSCROLL/YSCROLL fine scrolling. RSEL/CSEL 24/25-row and 38/40-column modes. Border flip-flops for border-opening tricks. Light pen ($D013/$D014). Raster interrupts.
- **Audio (SID):** 24-bit phase accumulator, 23-bit Fibonacci LFSR noise, all 4 waveforms combinable via AND. Ring modulation, hard sync, test bit. Real ADSR rate counter tables from die analysis with exponential decay. 12dB/octave state-variable filter (LP/BP/HP) with 31-point piecewise-linear cutoff table from 6581 chip measurements. Per-voice filter routing.
- **I/O (CIA):** Dual 16-bit timers with one-shot/continuous modes. TOD clock (BCD, 50Hz, latch-on-read, alarm with IRQ). Serial shift register (clocked by Timer A, ICR bit 3). Keyboard matrix (8x8). Interrupt control/masking.
- **Storage:** IEC serial bus with virtual 1541 drive — signal-level ATN/CLK/DATA protocol on CIA2 port A. D64 disk image parser with directory reading and sector chain following. Datasette via emu-tape PulseTimeline — TAP v0/v1 format, motor control ($01 bit 5), SENSE on CIA1 port B bit 4, data edge triggers CIA1 FLAG pin. PRG direct loading with BASIC pointer fixup.
- **Memory:** 64KB RAM + BASIC/KERNAL/character ROMs with 6510 bank switching. Page-table dispatch. Colour RAM at $D800.
- **Keyboard:** Full PETSCII mapping with shift-aware translation. RUN/STOP, CTRL, C= key.
- **Joystick:** Port 2 via CIA1 port A (active low). Numpad 8/2/4/6 + Numpad0/RAlt.
- **Shell:** F3/F4 save/load state, F5/F6 tape play/stop, F9 reset, Tab rewind, audio via cpal.

## Not implemented / accuracy gaps

### Nice to have
- **T64 format** — simple tape container
- **REU (RAM Expansion Unit)**
- **Multiple SID variants** (6581 vs 8580 filter differences)
- **True 1541 drive emulation** — the current virtual drive handles the IEC protocol but doesn't run the 1541's internal 6502. Needed for fastloaders and copy protection.

### Validation debt
- **Gated software-autoload tests** — 13 D64/TAP autoload tests sit `ignored`
  pending external archive paths.
- **Lorenz suite** — 250/265 pass; 15 are hardware-dependent skips (not failures,
  but the boundary isn't documented per-test here).

## Known unknowns / disproven hypotheses

- **Open: SID filter provenance.** The 31-point cutoff table is described as
  "from 6581 chip measurements" and the ADSR tables "from die analysis" — the
  underlying sources aren't cited in-repo. A prime verification target: confirm
  against the named die-analysis work before treating the curve as ground truth.
- **Open: 8580 vs 6581.** Only one SID filter model; the 8580 difference is
  unmodelled, so 8580-tuned music is unverified.
- **Verification targets** — VIC-II bad-line / BA-line / sprite-DMA cycle timing
  is validated by our own tests; cross-check against VICE and the primary VIC-II
  references (`emulators/c64/`) for the trick-dependent edge cases.
