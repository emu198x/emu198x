# Sega SG-1000 / SC-3000

## Status: Boots carts to title

The second donor extraction. Boots the Othello Multivision "007 James Bond" cart
to its level-select title. Headless extended system. Z80 + TMS9918A + SN76489A —
the same chip pair as ColecoVision, but with the **correct 3:2 VDP-phase clock**.

## What works

- **Z80 + TMS9918A + SN76489A**, with the accurate 3:2 VDP-dot-to-T-state phase
  counter (better than ColecoVision's initial 3:1).
- **Cart boot to title** — smoke `tests/cart_boot.rs` (first `.sg`).

## Not implemented / accuracy gaps

- **TMS9918A scanline-batched render** (shared family debt).
- **SC-3000 keyboard** — `set_pause_pressed` drives the NMI; the full 8255
  keyboard matrix isn't modelled.
- **Cart-mapper support** — base ceiling 48K; some late/Mark III carts bank-switch
  (out of scope; SMS will likely share the mapper layer).
- **Snapshot** — deferred. **No native window.**

## Known unknowns / disproven hypotheses

- **Open: SC-3000 keyboard** — unmodelled; the SG-1000 console path doesn't need
  it, but SC-3000 software will.
- **Verification target** — VDP per-dot timing (shared with the TMS9918 family).

## Validated against

- Othello Multivision cart → title; `tests/cart_boot.rs`.
