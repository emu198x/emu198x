# Sega SG-1000 / SC-3000

## Status: Boots carts to title

The second donor extraction. Boots the Othello Multivision "007 James Bond" cart
to its level-select title. Headless extended system. Z80 + TMS9918A + SN76489A —
the same chip pair as ColecoVision, but with the **correct 3:2 VDP-phase clock**.

## What works

- **Z80 + TMS9918A + SN76489A**, with the accurate 3:2 VDP-dot-to-T-state phase
  counter (better than ColecoVision's initial 3:1).
- **Cart boot to title** — smoke `tests/cart_boot.rs` (first `.sg`).

## Not implemented / accuracy gaps

- **SC-3000 keyboard** — `set_pause_pressed` drives the NMI; the full 8255
  keyboard matrix isn't modelled.
- **Cart-mapper support** — base ceiling 48K; some late/Mark III carts bank-switch
  (out of scope; SMS will likely share the mapper layer).
- **Snapshot** — deferred. **No native window.**

## Known unknowns / disproven hypotheses

- **Open: SC-3000 keyboard** — unmodelled; the SG-1000 console path doesn't need
  it, but SC-3000 software will.
- **Verification target** — VDP per-dot timing (shared with the TMS9918 family).

## Validated against

- Othello Multivision cart → title; `tests/cart_boot.rs`.

## Timing & cycle-accuracy

- **Master clock & dividers** — 10.738635 MHz. CPU = ÷3 ≈ 3.58 MHz; VDP dot = ÷2.
- **Timing model realised** — the best of the TMS9918 family: the **correct 3:2**
  VDP-dot-to-T-state phase counter **and** the shared **per-dot** VDP render
  (each pixel drawn at its dot; `ti-tms9918::tick`).
- **CPU timing** — Z80 cycle-accurate (§62); no Z80 bus-timing oracle.
- **Distance to full cycle-accuracy** — with 3:2 phase and per-dot render both in
  place, the SG-1000 is the family's closest to master-clock VDP accuracy;
  remaining gaps are CPU bus-cycle timing and IntAck verification.

## Tooling & drivability

- **Script / MCP** — `--script` + `--mcp` (operational-parity rollout).
- **Native window** — headless only (extended tier).
- **Disassembler** — pending the Asm198x shared Z80 disassembler.

## Peripherals & connectivity

- **Emulated now** — cartridge, joystick.
- **Period peripherals (emulatable)** — SC-3000 keyboard, tape (SF-7000), the
  SF-7000 disk/serial expansion.
- **Internet-capable** — **No** for the SG-1000; **Marginal** via the SF-7000
  expansion's RS-232C (period serial, no real net service).
