# Spectravideo SVI-328

## Status: Boots to SV-BASIC; keyboard types

Shows its SPECTRAVIDEO logo then SV extended BASIC 1.1 (`Ok`). Headless extended
system. Z80 + TMS9918A + AY-3-8910 + Intel 8255 PPI. (The MSX precursor — same
chip family.)

## What works

- **Boot to SV-BASIC** (2026-06-04) with the 32K system ROM (`svi111.rom`, md5
  `352f…35cc`).
- **Keyboard** — 11×8 matrix via the 8255 PPI (row select port C, column read
  port B), wired into the runtime (2026-06-05). Types `HELLO`.
- **Memory banking** via AY-3-8910 port B (R15) bit 1 (`bk21`).

## Not implemented / accuracy gaps

- **Cassette I/O** — via PPI port C bits 4-7, unwired (bits 0-3 do drive keyboard
  row select correctly).
- **Snapshot** — deferred. **No native window.**
- **SVI-318 sibling** — same stack, 16K RAM, slightly different matrix (variant
  flag).

## Known unknowns / disproven hypotheses

- **DISPROVEN (donor I/O map): VDP read on `$85`=keyboard.** Entirely wrong map.
  The VDP is *written* at `$80/$81` but **read at `$84/$85`**, and the vblank ISR
  reads status at `$85` to ack the interrupt — with `$85` pointed at the keyboard,
  the interrupt never cleared, the ISR never advanced, and the BIOS stalled on a
  flat cyan screen. Corrected against MAME `svi318`: VDP `$80/81` write `$84/85`
  read, PSG `$88/$8C/$90`, PPI `$94-$9A`, AY-port-B banking.
- **Verification target** — cassette load path (PPI port C).

## Validated against

- MAME `svi318.cpp` — I/O map + 11×8 keyboard matrix (ground-truthed vs the ROM).
- `svi111.rom` → SV-BASIC `Ok`; typing `HELLO` lands on screen.

## Timing & cycle-accuracy

- **Master clock & dividers** — Z80A at 3.58 MHz; TMS9918 dot ÷2. (Exact crystal
  — verify.)
- **Timing model realised** — TMS9918 now renders **per-dot** (each pixel drawn at
  its dot; `ti-tms9918::tick`); AY + 8255 PPI on the CPU clock.
- **CPU timing** — Z80 cycle-accurate (§62); no Z80 bus-timing oracle.
- **Distance to full cycle-accuracy** — exact VDP-dot/CPU phase.

## Tooling & drivability

- **Script / MCP** — `--script` + `--mcp` (operational-parity rollout).
- **Native window** — headless only (extended tier).
- **Disassembler** — pending the Asm198x shared Z80 disassembler.

## Peripherals & connectivity

- **Emulated now** — system ROM, keyboard.
- **Period peripherals (emulatable)** — the SVI expander bus (disk drive, 80-col,
  printer, Super Expander), cassette, joysticks.
- **Internet-capable** — **Marginal**: RS-232 cartridge + period modems; the
  later SVI-MSX line had MSX net options. No prioritised device.
