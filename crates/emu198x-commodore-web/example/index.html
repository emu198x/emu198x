Click the screen to type. On Amiga, the first click captures the mouse; use the Amiga pointer and press Escape to release. Escape is C64 RUN/STOP; Alt is Commodore. Shift+2 gives the C64 quotation mark.

C64: load PRG after the boot prompt, then type RUN or SYS. Disks require a 1541 ROM; type LOAD"*",8,1 then RUN. Amiga: insert a bootable ADF.
